# AI UGC Ad Content Generator

## Project Overview

This project demonstrates Prompt Engineering for generating
UGC-style advertising content for social media.

## Brand

boAt

## Product

boAt Nirvana Ion Wireless Earbuds

## Objective

Create an AI-powered prompt system capable of generating:

- Multiple advertising hooks
- UGC-style ad scripts
- CTAs
- Platform-specific content
- Social media captions

## Target Audience

- College students
- Gamers
- Music listeners
- Young professionals
- Commuters

## Platforms

- Instagram Reels
- Instagram Ads
- YouTube Shorts

## Prompt Framework

Brand/Product Context
        ↓
Target Audience
        ↓
Customer Problem
        ↓
Hook
        ↓
Problem
        ↓
Solution
        ↓
Product Benefits
        ↓
CTA
        ↓
Platform Adaptation

## AI Tool

ChatGPT

## Key Prompt Engineering Techniques

- Role prompting
- Context injection
- Audience specification
- Constraint-based prompting
- Tone control
- Structured output
- Platform adaptation
- Multiple-output generation

## Outcome

Created a reusable prompt system capable of producing
authentic UGC-style advertising content for a real product.

## Disclaimer

The scripts are AI-generated creative concepts for portfolio/
internship purposes and are not official boAt advertisements.
