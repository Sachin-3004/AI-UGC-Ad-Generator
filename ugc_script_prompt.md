# UGC Ad Script Prompt

Act as a professional UGC advertising scriptwriter.

Create a 30-40 second Instagram Reel advertisement for:

Brand: boAt
Product: Nirvana Ion Wireless Earbuds

Target audience:
College students and young professionals.

Use the following structure:

HOOK
→ Problem
→ Personal experience
→ Product introduction
→ Relevant features
→ Benefit
→ Soft CTA

The script must:

- Sound like a genuine recommendation
- Use first-person conversational language
- Avoid corporate advertising language
- Avoid exaggerated claims
- Mention only verified product features
- Keep sentences short
- Include natural pauses
- Be suitable for someone speaking directly to a phone camera

Include:

Voiceover
On-screen text
Suggested shot
CTA
